# English for Technical Interviews — From Scratch

> **EN:** A practical learning repository for explaining coding-interview solutions in clear, confident English.
>
> **VI:** Repository thực hành giúp bạn giải thích lời giải phỏng vấn coding bằng tiếng Anh rõ ràng và tự tin.

## Design philosophy / Triết lý thiết kế: Core vs. Upgrade

```text
[Input problem]
      |
      +--> 1. Core script (required)
      |      Simple English · Speak smoothly · No difficult words required
      |
      +--> 2. Upgrade (optional)
             Standard CS terms · Better phrasing · Stronger explanations
```

```text
[Bài toán đầu vào]
      |
      +--> 1. Core script (bắt buộc)
      |      Tiếng Anh đơn giản · Nói trơn tru · Không cần từ khó
      |
      +--> 2. Upgrade (lựa chọn)
             Thuật ngữ CS chuẩn · Văn phong tốt hơn · Diễn đạt sâu hơn
```

## 1. Core — Speak smoothly first, perfect later / Nói trơn trước, hoàn hảo sau

> **EN — Goal:** Explain the optimal algorithm in **six to eight short sentences** without getting stuck.
>
> **VI — Mục tiêu:** Trình bày được giải thuật tối ưu bằng **6–8 câu ngắn** mà không bị vấp.

> **EN — Principle:** Prefer common, memorable, and direct words.
>
> **VI — Nguyên tắc:** Ưu tiên từ phổ thông, dễ nhớ và đi thẳng vào ý chính.

| Core wording | Upgrade wording | Nghĩa tiếng Việt |
| --- | --- | --- |
| `increase / decrease` | `increment / decrement` | tăng / giảm |
| `count characters` | `count character frequencies` | đếm ký tự / đếm tần suất ký tự |
| `sorting takes the most time` | `sorting dominates the time complexity` | sorting tốn nhiều thời gian nhất / chi phối time complexity |

> **EN — Done means done:** If you can say the English column without looking at the document, you have completed the lesson.
>
> **VI — Hoàn thành nghĩa là hoàn thành:** Nếu bạn nói được cột tiếng Anh mà không nhìn tài liệu, bạn đã xong bài học.

## 2. Upgrade — Learn more when you are ready / Nâng cấp khi bạn sẵn sàng

> **EN — Goal:** Build standard Computer Science vocabulary and explain more detailed trade-offs.
>
> **VI — Mục tiêu:** Mở rộng vốn từ chuẩn Computer Science và giải thích các đánh đổi chi tiết hơn.

> **EN — Principle:** This section is optional. It is not a test and should never block progress in the Core section.
>
> **VI — Nguyên tắc:** Đây là phần lựa chọn, không phải bài kiểm tra và không được cản bạn hoàn thành phần Core.

| Typical content (EN) | Nội dung thường có (VI) |
| --- | --- |
| Brute-force and sorting alternatives | Các hướng brute force và sorting |
| Time and space complexity comparisons | So sánh time và space complexity |
| Trade-offs between approaches | Đánh đổi giữa các cách làm |
| Edge cases and changes in constraints | Edge cases và thay đổi về constraints |
| More natural or more technical phrasing | Cách diễn đạt tự nhiên hoặc kỹ thuật hơn |

## Golden rule / Nguyên tắc vàng

> **EN — Core constraint:** The Core script must prioritize simplicity and confidence over sophisticated vocabulary. High-level CS jargon belongs exclusively in the Upgrade section.
>
> **VI — Ràng buộc của Core:** Core script phải ưu tiên sự đơn giản và tự tin hơn từ vựng phức tạp. Thuật ngữ CS nâng cao chỉ thuộc về phần Upgrade.

## How to use a lesson / Cách học một bài

| Step | English | Tiếng Việt |
| --- | --- | --- |
| 1 | Read the Vietnamese meaning in the Core script. | Đọc ý nghĩa tiếng Việt trong Core script. |
| 2 | Say the English sentence aloud. | Nói to câu tiếng Anh. |
| 3 | Repeat until you can explain the full Core script without looking. | Lặp lại đến khi bạn nói được toàn bộ Core script mà không nhìn. |
| 4 | Stop there, or learn one small item from Upgrade if you still have energy. | Dừng ở đó, hoặc học thêm một mục nhỏ trong Upgrade nếu bạn còn sức. |

> **EN:** The objective is not to sound advanced. The objective is to explain your idea clearly, correctly, and with confidence.
>
> **VI:** Mục tiêu không phải là nói thật cao cấp. Mục tiêu là giải thích ý tưởng rõ ràng, đúng và tự tin.
