# [TÊN BÀI TOÁN]

> Mục tiêu của một bài: nói rõ được **một cách giải tối ưu** bằng tiếng Anh đơn giản. Không cần học hết trang trong một lần.

`|` = ngắt nhẹ giữa các cụm ý. **Bold** = từ mang thông tin chính, nên nhấn rõ hơn. Mỗi cụm ý ngắn thường chỉ cần một từ nổi bật.

## Cách học tài liệu này

1. Chỉ học phần **Core** trước: nói được 6–8 câu không nhìn cột EN.
2. Đọc lại cột **EN — Thought Group**: rõ ý → đúng nhịp → rồi mới tăng tốc.
3. Mỗi lần chỉ chọn tối đa 3–5 từ hoặc cụm từ mới.
4. Khi Core đã trơn, mới xem phần **Upgrade**. Phần này là lựa chọn, không phải bài kiểm tra.

## 1. Core script — học trước

> Thay nội dung trong `[ ... ]`. Cột **Cue** chỉ để nhắc ý, không cần đọc khi phỏng vấn.

| Cue | VI | EN | EN — Thought Group |
| --- | --- | --- | --- |
| Bài toán | Bài toán này yêu cầu `[mô tả ngắn mục tiêu]`. | This problem asks us to `[short goal]`. | This problem **ASKS** us \| to `[short goal]`. |
| Kiểm tra sớm | Đầu tiên, nếu `[early condition]`, thì `[result]`. | First, if `[early condition]`, then `[result]`. | **FIRST** \| if `[early condition]` \| then `[result]`. |
| Cách làm | Em dùng `[data structure / approach]` để `[purpose]`. | I use `[data structure / approach]` to `[purpose]`. | I use `[data structure / approach]` \| to `[purpose]`. |
| Bước 1 | Với `[first input / action]`, em `[step 1]`. | For `[first input / action]`, I `[step 1]`. | For `[first input / action]` \| I `[step 1]`. |
| Bước 2 | Với `[second input / action]`, em `[step 2]`. | For `[second input / action]`, I `[step 2]`. | For `[second input / action]` \| I `[step 2]`. |
| Điều kiện kết quả | Nếu `[condition]`, thì `[answer]`. | If `[condition]`, then `[answer]`. | If `[condition]` \| then `[answer]`. |
| Time complexity | Ta duyệt input một lần, nên time complexity là `O(...)`. | We scan the input once, so the time complexity is `O(...)`. | We scan the input **ONCE** \| so the time complexity is **O(...)**. |
| Space complexity | Space complexity là `O(...)` vì `[reason]`. | The space complexity is `O(...)` because `[reason]`. | The space complexity is **O(...)** \| because `[reason]`. |

### Layer reasoning nhẹ

Trước khi viết câu, xác định chuỗi: **Actor → Action → Mechanism → Result**.

```text
[input / component] → [does what] → [how the effect happens] → [concrete result]
```

Không cần biến bốn phần thành bốn câu. Mục tiêu là làm quan hệ nguyên nhân và kết quả hiện rõ trong lời nói.

## 2. Core vocabulary — chọn tối đa 5 mục

| English | Nghĩa tiếng Việt | Câu dễ dùng |
| --- | --- | --- |
| input | dữ liệu đầu vào | `We scan the input once.` |
| count | đếm / số lượng | `I count each character.` |
| check | kiểm tra | `We check every count.` |
| increase / decrease | tăng / giảm | `I increase the count.` |
| result | kết quả | `Then we return the result.` |

## 3. Upgrade — chỉ học sau khi Core đã trơn

### So sánh approaches

| Cue | VI | EN |
| --- | --- | --- |
| Nêu phương án khác | Một cách khác là `[approach]`. | Another approach is `[approach]`. |
| Điểm yếu | Cách này dễ hiểu, nhưng `[limitation]`. | This approach is simple, but `[limitation]`. |
| Complexity | Vì vậy, time complexity là `O(...)`. | So the time complexity is `O(...)`. |
| Lý do chọn cách tối ưu | Cách này tốt hơn vì `[reason]`. | This approach is better because `[reason]`. |

### Cụm câu nâng cao, không bắt buộc

| Chunk | Nghĩa |
| --- | --- |
| `Before I start coding, I’d like to explain the approaches first.` | Dẫn vào phần giải thích các cách làm. |
| `In the worst case, ...` | Nói về trường hợp xấu nhất. |
| `What we really care about is ...` | Nêu insight chính. |
| `This brings the time complexity down to O(...).` | Nhấn mạnh việc tối ưu complexity. |

- [ ] Nếu còn sức, em học thêm **một** câu ở phần Upgrade.
